## Field Notes

기술은 Specification만으로 평가하기 어렵습니다. 상용망에서는 항상 다음 질문이 따라옵니다.

- 기존 시스템과 실제로 어떻게 연동되는가?
- 장애가 발생했을 때 서비스는 어디까지 유지되는가?
- 성능은 Lab이 아니라 운영 조건에서도 유지되는가?
- Scale이 증가하면 어떤 부분이 먼저 병목이 되는가?
- 운영자가 실제로 관리할 수 있는 구조인가?
- 기술검증이 끝난 뒤 상용서비스와 매출로 연결될 수 있는가?

**BJ Tech Notes**는 이런 질문을 실제 프로젝트와 사업개발 경험을 기반으로 기록하는 공간입니다.
